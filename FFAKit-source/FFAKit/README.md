# FFAKit

FFAサーバー用のキット作成・編集・配布プラグイン(Paper 26.2 / Java 25)。
FFAのゲームシステム(アリーナ・キル判定など)は含みません。

## 1. jarの作り方(GitHub Actions・パソコンに何も入れなくてOK)
1. github.com で無料アカウントを作り、新しいリポジトリ(Public/Private どちらでも可)を作る。
2. このフォルダの中身をすべてアップロードする(`.github` フォルダも必ず含めること)。
   - 「Add file」→「Upload files」に、フォルダの中身をドラッグ&ドロップ。
3. 「Commit changes」を押す。
4. 上部の「Actions」タブ → 「Build FFAKit」→ 最新の実行をクリック(緑のチェックになるまで数分待つ)。
5. ページ下の「Artifacts」から `FFAKit` をダウンロード → zipを解凍すると `FFAKit.jar`。

赤い×になった場合は、失敗した実行を開き、赤くなったステップのログを コピーして開発者(Claude)に貼ってください。

## 2. 導入方法
1. `FFAKit.jar` をサーバーの `plugins` フォルダへ入れる。
2. サーバーを再起動する(Paper 26.2 / Java 25 が必要)。
3. `plugins/FFAKit/config.yml` が自動生成される。

## 3. コマンド
| コマンド | 内容 | 必要な権限 |
|---|---|---|
| `/ffakit book` | キット編集本を1冊もらう(プレイヤー専用) | OPレベル4以上 |
| `/ffakit setbase <キット名>` | 今の持ち物・装備を基本キットとして保存(新規作成/上書き。プレイヤー専用) | OPレベル4以上 |
| `/ffakit delete <キット名>` | キットを完全削除(全員の個人カスタムも削除) | OPレベル4以上 |
| `/ffakit reset <プレイヤー> <キット名>` | そのプレイヤーの個人カスタムだけ削除 | OPレベル4以上 |
| `/kit give <プレイヤー名/@p/@a> <キット名>` | キットを配布(コンソール・コマンドブロック・他プラグインからも可) | 制限なし(仕様どおり) |

- コンソールは `delete` / `reset` を実行できます。コマンドブロックは `/ffakit` を実行できません。
- OPレベル4の判定は、サーバー直下の `ops.json` の `level` を読んで行います。
  読み込めない環境では config.yml の `ops-json-check: false` にすると、OPなら許可になります。

## 4. 使い方(キット作成 → 編集 → 配布)
1. キットにしたい装備・持ち物を整えて `/ffakit setbase Knight` を実行(基本キットができる)。
2. `/ffakit book` でキット編集本をもらい、**左クリック**でキット選択GUIを開く。
3. キットのアイコンをクリック(左右どちらでも可)すると編集GUIが開く。
   - 下側36スロット = 通常インベントリ(位置もそのまま保存される)
   - 上側: ヘルメット(10)・チェストプレート(11)・レギンス(12)・ブーツ(13)・オフハンド(15)
   - 防具を**右クリック**すると Armor Trim GUI が開く(素材・模様をクリックで循環、完成品をクリックで確定)
   - BARRIER(49)= 保存せずキャンセル。普通に閉じると個人カスタムとして保存。
4. 配布: `/kit give @a Knight` など。個人カスタムがあればそれ、なければ基本キットが渡される。

### 編集GUIでできない操作(安全のため)
Shiftクリック、ダブルクリック、Q(ドロップ)、F(オフハンド交換)、中クリック、非防具アイテムの右クリック(半分取り)は禁止です。
編集中はダメージを受けず、アイテムのドロップ・拾得もできません。

### 何も変更せずにGUIを閉じた場合
個人カスタムは作られません(基本キットを後で変更したときに反映されなくなるのを防ぐため)。

## 5. データ保存場所
| 場所 | 内容 |
|---|---|
| `plugins/FFAKit/config.yml` | キットアイコン設定、ops-json-check |
| `plugins/FFAKit/kits.yml` | 基本キット(キット名・登録順・アイコン・中身) |
| `plugins/FFAKit/players/<UUID>.yml` | プレイヤーごとの個人カスタム |
| `plugins/FFAKit/backup/<UUID>.yml` | 編集中の「元の所持品」バックアップ(編集終了で自動削除) |

アイテムはPaper標準のバイト列シリアライズ(Base64)で保存します。Armor Trimなどの情報が失われません。
そのため YAML を手で編集することはできません。保存は「一時ファイル → 本ファイルへ置換」で行います。

## 6. 異常終了について
JVMクラッシュ・OS強制終了・プロセスkillなど、Java/Paperの終了処理が実行されない異常終了は、
プラグイン単独で100%復旧を保証できません。ただし編集開始時に元の所持品を `backup/` へ書き出しており、
次回ログイン時に自動で復元します。ログアウト・キック・プラグイン無効化は安全に処理されます。
